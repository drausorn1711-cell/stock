# StockMaster - ระบบจัดการคลังสินค้า (Inventory Management System)

ระบบจัดการสินค้าและสต็อกสินค้าแบบเรียลไทม์ พัฒนาด้วย Node.js (Express), SQLite3 และส่วนติดต่อผู้ใช้ด้วย Tailwind CSS

---

## 🚀 วิธีเปิดใช้งานระบบ (Quick Start)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ (แนะนำสำหรับ Windows)
- ดับเบิลคลิกที่ไฟล์ **`start.bat`** 
- ตัวโปรแกรมจะเริ่มระบบเซิร์ฟเวอร์ และเปิดเบราว์เซอร์ไปยัง `http://localhost:3000` ให้อัตโนมัติทันที

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
1. เปิด Terminal หรือ PowerShell ในโฟลเดอร์นี้
2. ติดตั้ง Dependencies (กรณีโหลดโปรเจกต์ใหม่):
   ```bash
   npm install
   ```
3. เริ่มต้นรันเซิร์ฟเวอร์:
   ```bash
   node server.js
   ```
4. เปิดเว็บเบราว์เซอร์ไปที่:
   ```
   http://localhost:3000
   ```

## 🌟 ฟีเจอร์หลักของระบบ

1. **แดชบอร์ดสรุปสถิติสต็อก**:
   - รายการสินค้าทั้งหมด
   - จำนวนสต็อกรวม
   - การแจ้งเตือนสินค้าสต็อกใกล้หมด (ไฮไลต์สีส้ม/แดงอัตโนมัติ)

2. **ระบบจัดการสินค้า**:
   - เพิ่มสินค้าใหม่ พร้อมรูปภาพ (รองรับการอัปโหลดไฟล์ หรือกด `Ctrl + V` วางรูปภาพได้ทันที พร้อมระบบย่อรูปภาพ Canvas อัตโนมัติ)
   - ปรับสต็อกด่วนทันใจ (`+1` รับเข้า / `-1` เบิกออก)
   - แก้ไขข้อมูลสินค้า (ชื่อ, ขนาด/SKU, หมวดหมู่, สต็อก, จุดเตือน)
   - ลบสินค้าที่ไม่ต้องการ

3. **ระบบค้นหาและกรองข้อมูล**:
   - ค้นหาแบบเรียลไทม์ตามชื่อสินค้า หรือ SKU/ขนาด
   - ตัวกรองตามหมวดหมู่ (ของสด, ของแห้ง, น้ำพริก, สมุนไพร, ของนำเข้า)
   - ตัวกรองตามสถานะสต็อก (สต็อกปกติ, ใกล้หมด, หมดสต็อก)

4. **ประวัติความเคลื่อนไหว (Inventory Audit Logs)**:
   - บันทึกทุกความเคลื่อนไหวอัตโนมัติ (รับเข้า, เบิกออก, เพิ่มสินค้า, แก้ไข) พร้อมวัน-เวลา

5. **ส่งออกรายงาน (Export)**:
   - ส่งออกเป็นไฟล์ **Excel (.xlsx)**
   - ส่งออกเป็นไฟล์ **PDF** แบบแนวนอน สวยงามพร้อมพิมพ์

---

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)

- **Backend**: Node.js, Express.js, SQLite3
- **Frontend**: HTML5, Tailwind CSS, Lucide Icons
- **Export Tools**: SheetJS (XLSX), html2pdf.js
- **Database**: SQLite3 (`inventory.db`)
